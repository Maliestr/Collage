# Collage

Консольная программа для автоматического переименования изображений в директории.

## Инструкция

До начала использования программы, все изображения, которые вы хотите переименовать нужно перенести в одну папку. При запуске программа попросит вас выбрать эту папку.

Программа работает по двум алгоритмам:
1. С указанием размеров изображений в коллаже;
2. Без указания размеров.

Выбрав создание коллажей с новыми размерами фотографий, укажите размеры.
После создания коллажа(ей), возьмите получившееся изображение(я) и отправьте в нейросеть, с указанным в программе запросом.

Затем полученный ответ, скопируйте и вставьте в программу.

Откройте папку, там будут лежать ваши изображения с новыми именами.

## Цели и задачи

### Цели проекта
- Автоматизация рутинного переименования изображений - избавить пользователя от ручного переименования десятков/сотен файлов.
- Интеграция с нейросетью - использовать ИИ для генерации осмысленных имён на основе содержимого изображений, а не шаблонных IMG_001.jpg.

### Задачи проекта
- Реализовать два алгоритма работы:
  - с указанием размеров изображений в коллаже;
  - без указания размеров (автоматический режим).
- Создавать коллажи из изображений.
- Парсить ответ и переименовывать файлы - сопоставить полученные имена с исходными изображениями и переименовать их в директории.
- Обеспечить работу в консольном режиме - минималистичный интерфейс без GUI.

### Какую бизнес-задачу решал бы этот проект
В бизнес-контексте Collage закрывает задачу массовой каталогизации и осмысленного именования медиафайлов. Конкретные сценарии:
- Обработка фотоархивов - фотографы, видеографы, контент-менеджеры получают сотни снимков с камер. Программа даёт им понятные имена по содержимому, что ускоряет поиск и сортировку.
- Работа с дизайн- и маркетинговыми материалами - быстрый разбор больших папок с изображениями по смыслу, а не по дате съёмки.
- Экономия времени сотрудника - переименование 200 файлов вручную занимает часы; автоматизация с ИИ сокращает это до минут.
